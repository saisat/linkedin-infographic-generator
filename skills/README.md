# Skills

[Back to the project](../README.md)

Ask your agent for a skill by name, or point it at the `SKILL.md`. `.claude/skills` and `.agents/skills` link to this folder.

## Motion (the main focus)

| Skill | Use it to |
|---|---|
| [motion-infographic](motion-infographic/SKILL.md) | Build a flat 2D animated infographic, exported as a 1080 x 1350 still, MP4 and GIF. Two starters: **feed** (phone-readable steps, stats and icon badges) and **map** (a system-map poster with stages, icon cards, logo chips, connectors and decisions). |
| [diorama-3d](diorama-3d/SKILL.md) | Tell a system as a 3D place in three.js, with a 2-second build-in and a seamless loop, exported as a still, MP4 and GIF. |

## Visuals

| Skill | Use it to |
|---|---|
| [graphics-designer](graphics-designer/SKILL.md) | Create a static graphic, carousel or banner from the brand rules, or as a neutral unbranded draft. Holds the shared copy rules for every graphic. |
| [flowchart](flowchart/SKILL.md) | Create editable Excalidraw flowcharts, system maps and funnels with semantic icons and verified routing. |
| [brand-system](brand-system/SKILL.md) | Set up or update the visual identity and the tokens every starter reads. |
| [brand-review](brand-review/SKILL.md) | Review a rendered graphic or animation for clarity, identity and export quality; fix it when asked. |
